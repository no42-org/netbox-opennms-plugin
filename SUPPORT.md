# Support

- **Questions & usage help** — open a
  [GitHub issue](https://github.com/no42-org/netbox-opennms-plugin/issues/new/choose)
  with the `question` label.
- **Documentation** — the
  [contributor & user guide](https://no42-org.github.io/netbox-opennms-plugin/)
  covers installation, the local NetBox + OpenNMS stack, and how syncing works.
- **Bugs & feature requests** — use the issue templates.
- **Security problems** — see [SECURITY.md](./SECURITY.md); never a public issue.
